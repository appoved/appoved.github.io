プライバシーポリシー

最終更新日：2026年11月15日

本プライバシーポリシーは、Yury Bondar（Appoved）が開発・公開するモバイルアプリケーション（FlyMoney およびその他のユーティリティアプリを含み、総称して「本アプリ」といいます）に適用されます。

1. お使いの端末にローカル保存されるデータ

本アプリは、ユーザー登録やアカウント作成を必要とせずに動作するよう設計されています。選択した通貨、アクティブな入力欄、オフライン利用のためにキャッシュされた為替レートなどの設定および動作データは、お使いの端末のローカル領域にのみ保存され、開発者の個人サーバーへ送信されることはありません。また、正確な GPS 位置情報の要求や収集も行いません。

2. 第三者サービスとデータ収集

最新機能の提供および本アプリの無料提供を維持するため、信頼性の高い第三者サービスを組み込んでいます：

  • 広告配信（Yandex Mobile Ads SDK）：本アプリでは Yandex Mobile Ads を通じてバナー広告を表示します。この SDK は、広告の配信・測定・パーソナライズのために、端末の技術情報、IP アドレス、広告識別子（iOS の IDFA や Android の Google 広告 ID など）を自動的に収集する場合があります。詳細は Yandex プライバシーポリシーをご確認ください。
  • 為替レート提供元（Frankfurter API）：参考為替レートを取得するため、本アプリは公開金融 API（Frankfurter など）へ標準的な HTTP リクエストを送信します。これらのリクエストでは、データ配信に必要な技術的ネットワークヘッダ（IP アドレスなど）のみが送信され、ユーザーの個人情報は含まれません。

3. 匿名の製品アナリティクス

安定性と使いやすさの向上を目的として、集計・匿名化された技術テレメトリ（アプリのバージョン、OS、端末の種類、クラッシュ診断情報、一般的な画面操作など）を収集する場合があります。ユーザーが入力した金額が記録または送信されることは一切ありません。

4. お客様のプライバシーに関する権利と選択

お住まいの地域（EEA/GDPR およびカリフォルニア州/CCPA を含む）に応じて、パーソナライズ広告およびローカルデータを管理する権利があります：

  • 端末のプライバシー設定から、広告識別子のリセットまたは利用制限を行うことができます（iOS：「設定」>「プライバシーとセキュリティ」>「トラッキング」、Android：「設定」>「プライバシー」>「広告」）。
  • アプリのストレージを消去するか、本アプリをアンインストールすることで、ローカルに保存されたすべてのアプリデータをいつでも削除できます。

5. お子様のプライバシー

本アプリは一般利用者向けであり、13歳未満（またはお住まいの法域で適用されるデジタル同意年齢未満）のお子様を対象としていません。開発者が故意にお子様から個人情報を収集することはありません。

6. 本ポリシーの変更

本プライバシーポリシーは随時更新される場合があります。変更があった場合は、更新日を改訂したうえで本ページに掲載します。
